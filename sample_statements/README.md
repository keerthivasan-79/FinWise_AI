# FinWise sample bank statements

Use these files on the Transactions page in **Import Bank Statement**.

## How to import

1. Open FinWise and sign in.
2. Go to **Transactions**.
3. Add or select an account.
4. In **Import Bank Statement**, choose one of these CSV files.
5. Click **Preview Statement**.
6. Review the detected rows, then click **Confirm Import**.

## Files

- `hdfc_style_debit_credit.csv`: Uses Date, Narration, Withdrawal Amount and Deposit Amount columns.
- `sbi_style_amount_drcr.csv`: Uses Txn Date, Description, Amount and Dr/Cr columns.
- `icici_style_value_date.csv`: Uses Value Date, Particulars, Debit and Credit columns.
- `upi_wallet_style.csv`: Uses Transaction Date, Details, Transaction Type and Transaction Amount columns.

These are fake sample records for testing only.
